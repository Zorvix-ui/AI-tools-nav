## 简介

Claude Code是Anthropic推出的命令行编程助手，2026年以54%市场份额碾压Cursor和Copilot。最大不同：它不是IDE插件，是运行在终端里的Agent。你在命令行里说"修这个Bug"或"重构这个模块"，它自己读代码、改代码、跑测试、提交Git，全自动干完。

## 核心功能

- **终端原生Agent**：命令行里直接对话，不需要打开IDE
- **全自动编程**：从理解需求到写代码到测试到Git提交一条龙
- **代码库深度理解**：自动索引全项目代码
- **CI/CD集成**：可挂到GitHub Actions里自动修Bug
- **Git原生操作**：自动创建分支、提交、写PR描述
