## 简介

GitHub 不只是一个 Git 托管服务。Copilot 重新定义了编程方式，Actions 解决了 CI/CD，Codespaces 让开发环境上云。2026 年 GitHub 有 1.5 亿+ 开发者，是全球最大软件社区。

## 核心功能

- **代码托管**：无限私有仓库，Pull Request 代码审查
- **GitHub Copilot**：AI 编程助手，代码补全、Bug 修复、重构
- **GitHub Actions**：CI/CD 流水线，7000+ 社区 Action
- **Codespaces**：云端开发环境，浏览器里跑 VS Code
- **Projects**：类 Notion 的项目管理视图
